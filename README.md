# 🌱 KrishiLens

**AI-powered pesticide label reader for Indian farmers.**

## 📌 Problem Statement
Many Indian farmers struggle to understand pesticide labels due to technical terms, language barriers, and complicated safety instructions. This can lead to incorrect usage and unsafe handling.

## 💡 Our Solution
KrishiLens uses **Gemma 4** to analyse pesticide label images and explain the information in simple language, helping farmers understand important instructions and safety precautions.

## ✨ Features
- 📸 Upload or capture pesticide label images.
- 🤖 AI-powered label analysis using Gemma 4.
- 🌐 Explanations in English, Hindi, and Gujarati.
- 🛡️ Highlight important warnings and safety precautions.
- 💬 Ask questions about the scanned label.
- ⚠️ Flag blurry or unreadable information instead of guessing.

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **AI Model:** Gemma 4
- **Version Control:** Git and GitHub

## 🔄 How It Works
1. Upload a pesticide label image.
2. Gemma 4 analyses the visible information.
3. The application extracts important details and warnings.
4. The user receives a simple explanation in their preferred language.

## 🚀 Future Scope
- Voice-based assistance.
- Support for more Indian languages.
- Text-to-speech explanations.
- Improved support for low-connectivity areas.
